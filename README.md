# 本地账单分析（Qwen + Ollama）

把 PDF 月结单变成分类好的 Dashboard，并可以用聊天的方式问"这个月哪里花多了"。全部在本机运行，账单不会上传到任何地方。

## 启动

1. 确保 Ollama 在运行，并且已经有 Qwen 模型（命令行 `ollama list` 能看到，比如 `qwen2.5:7b`、`qwen3:8b`）
2. 双击 `run.bat`（第一次会自动安装 pdfplumber、plotly 等依赖）
3. 浏览器会打开 http://localhost:8501

也可以手动运行：
```
pip install -r requirements.txt
python -m streamlit run app.py
```

想先试一下？`samples` 文件夹里有 3 份模拟账单（两个月的信用卡 + 一个月的储蓄账户），直接上传就能看到效果。试完在「导入账单」页底部清空数据，再导入你自己的。

## 使用流程

1. **导入账单**：上传 PDF（可一次多份）。同一份账单重复导入不会重复计算。账单有密码的话（新加坡很多银行用 NRIC 或生日做密码），在左侧栏填上
2. **Dashboard**：左侧栏选月份，看总支出、分类占比、和前几个月平均的对比、趋势、花钱最多的商户
3. **对话分析**：直接问，比如「这个月哪里花多了」「餐饮为什么比平时多」「有哪些订阅」
4. **交易明细**：分类不对就直接改，保存后同一商户以后都会自动按你改的分

## 它是怎么工作的

- **解析**：先用规则识别 PDF 里的交易行（支持信用卡的「日期 描述 金额」和储蓄账户的「金额 + 余额」两种格式，描述跨行也能拼起来）。规则认不出时，自动让 Qwen 从文字中提取
- **分类**：你手动改过的 > `config.py` 里的关键词规则 > Qwen 判断 > 其他。Qwen 的判断会缓存，同一商户只问一次
- **分析**：所有数字由 pandas 计算，Qwen 只负责解读，不做加减法，避免本地模型算错数

## 常见调整（都在 `config.py`）

| 想做的事 | 改哪里 |
|---|---|
| 换默认模型 | `DEFAULT_MODEL`（侧边栏也能直接切换） |
| 常去的店总是分错 | 在 `KEYWORD_RULES` 里加一行，比如 `("KOPI", "餐饮")` |
| 加/改分类 | `CATEGORIES` |
| 回答被截断或不完整 | 调大 `NUM_CTX`（显存够的话可以 16384） |

## 注意事项

- 月份按**交易日期**划分，不按账单周期。所以最新一个月通常不完整，对比时 Dashboard 和 Qwen 都会考虑这一点
- 同时导入储蓄账户和信用卡账单时，账户里"还信用卡"的那笔默认不计入支出（避免重复算），可在左侧栏「不计入支出的分类」调整
- 扫描件（图片）PDF 没有文字，目前不支持
- 数据保存在 `data` 文件夹：`transactions.csv`（可用 Excel 打开）和 `merchant_categories.json`（分类记忆）

## 解析不对怎么办

导入时每个文件下面都有「查看原始文本」。如果某家银行的格式没认出来，把那段文字（删掉卡号、姓名、地址）发给我，我可以帮你调整解析规则。
